## Analysis Notes

### Key Findings

**1. Zero Data Collection**
Savage Interactive explicitly states: "Savage does not collect or share any data when using the Applications." This blanket statement covers all categories of data.

**2. Local-Only Storage**
All user content stays on the device:
- Artwork and movies
- Time-lapse videos
- Brushes and color palettes
- All project files

There is no cloud backup, no external storage, and no data synchronization.

**3. No Account Required**
Users are not required to create an account or log in to access any features or their data. This means no email addresses, passwords, or identity data is collected.

**4. No Network Connection**
The app does not connect to any Savage web services at any time. This ensures:
- No data transmission to servers
- No analytics tracking
- No online advertising
- No remote data storage

**5. Camera Features Without Data Collection**
Optional camera features (FacePaint using TrueDepth API, Palette Capture using camera) process data locally:
- TrueDepth data is not collected or stored
- Camera data is not collected or stored
- FacePaint works entirely on-device

**6. User Control Over Data**
Since everything is stored locally, users have complete control:
- Deleting the app removes all data
- No need to request data deletion from the company
- No data retained on external servers
- No need to contact support for data removal

### Policy Gap

**Policy Change Notification**
The privacy policy does not specify how users are notified of changes. This is a minor gap in an otherwise exemplary policy.
